経営者育成 Daily Dashboard Ver.6

Ver.5からの主な追加
- 毎日の「自社分析｜今日調べること」を追加
- ①社内資料・実態で確認する
- ②担当者に聞く
- ③外部情報で調べる
- ④最低限集めたい数字
の4分類で表示
- 今日のテーマに応じて、法令・価格・顧客・設備・競合等の重点確認ポイントも表示

使い方
1. 今日の学習テーマを理解
2. 自社分析欄から2～3項目を選んで確認
3. 「事実」「仮説」「未確認」に分けて学習メモへ記録
4. ChatGPT開始文を使ってレビュー
5. 今日を完了

注意
すべての調査項目を1日で集める必要はありません。
実際の社内数値・顧客情報・契約情報は公開GitHub Pages上には直接入力しないことを推奨します。
